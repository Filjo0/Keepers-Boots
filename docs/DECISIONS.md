# Scope decisions

## Accepted
| Decision | Reason |
|---|---|
| Keeper distribution under pressure first | A narrow fan interaction with inspectable evidence |
| Three scenarios | Clear preference under assumptions, time pressure, then uncertainty |
| Available-information boundary | No hindsight also requires excluding unseen present/past truth |
| Deterministic calculations | Numbers and spatial tests must be reproducible |
| Analyst plus reviewer | Interpretation and challenge are distinct jobs; measure their benefit |
| Original synthetic generator | Required data can be designed and documented |
| A$0 local Microsoft workflow first | Verify the integration without billable models or cloud resources |
| Draft original principles | Private Coach KB cannot become public project content |

## Conditional
One keeper-to-midfielder receiving step after the complete keeper MVP:
scripted refreshes and information age only.
Do not claim head/eye tracking, actual awareness or memory modelling.

## Deferred ideas
| Idea | Decision |
|---|---|
| Full scanning/head/body/visibility model | Too much additional modelling for this submission |
| Ideal criteria for every position | Role, phase, pressure and team instructions change the criteria |
| Effort/fuel indicators | Outside MVP; workload is not measured fatigue or remaining energy |
| Calories and food/drink suggestions | Outside MVP; per-action physiology and individual prescriptions unsupported |
| Substitution advice / Coach's Eye | Requires additional tactical/causal assumptions and rights-cleared knowledge |
| Passing Story / Press Escape | Possible later use of the same geometry and evidence engine |
| Tackles and why they happened | Intent/technique cannot be inferred from sparse events |
| Free-kicks, penalties and sweeping | Additional ball-flight/reach models and separate scenario review |
| Strongest players / what a star would do | No unsupported real-player rankings, intentions or ratings |
| H2H / Rematch | Needs comparable synthetic contexts; scoreline alone is insufficient |
| Height, weight, age, speed matchups | Use explicit simulated capacities; traits do not establish performance |
| Fan debate, accessibility audio, multilingual breadth | Later additions after the main loop is reliable |
| Large event platform / many agents | Add only when a measured need exists |
| Your face on a player | Defer realistic swapping; distinguish original avatars from modified real-player footage, and test value before photo processing |
| Celebrate alongside the scoring team | Possible later explanatory goal-recap extension; needs a scoring sequence and animation beyond the keeper MVP |
| Players perform your celebration | Defer custom motion capture; test selectable original gestures first if an engagement extension is justified |

These celebration proposals are engagement hypotheses, not accepted implementation work. Their strongest cases, failure modes and proposed tests are in [the critical review](IDEA_STRESS_TEST.md). Entertainment can be central to the experience; an appearance or gesture change alone does not supply match interpretation.

## Corrections retained
- Tracking frequency is an engineering choice, not a hackathon mandate.
- A drop in running does not demonstrate fatigue.
- Positive timing margin is not completion probability.
- A successful action is not proof it was best.
- A real-world scientific finding is not validation of this simulator.
- Synthetic data quality and fan understanding must be evaluated separately.
- Neither the keeper concept nor an alternative has a predicted winning score or demonstrated market demand.
- Do not claim an exact face-swap competitor feature without checking its source.
- A recap such as "2 of 3 choices correct" needs a defensible scoring basis; neither script agreement nor geometry supplies one automatically.
