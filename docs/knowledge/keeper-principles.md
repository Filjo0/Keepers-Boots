# Original keeper principles - draft v0.1

Newly written for this project. Human coaching review is pending.
These are scoped review prompts, not universal laws, optimal policies or copied KB entries.

| ID | Situation | Principle |
|---|---|---|
| K01 | Any decision | Assess options using the information available before the action. |
| K02 | Outcome review | Execution and outcome can differ from the quality of the original choice. |
| K03 | Receiving pressure | Consider whether there is enough time to prepare and release the action. |
| K04 | Ground distribution | Consider opponents who can reach the passing route, not only the target. |
| K05 | Choosing an outlet | A nearby teammate can still be difficult to reach safely. |
| K06 | Wide distribution | A wider route can change pressure and travel-time trade-offs. |
| K07 | Long clearance | Relief from immediate pressure does not establish who wins the next possession. |
| K08 | Turnover exposure | Where possession might be lost matters alongside whether it might be lost. |
| K09 | Uncertain information | Old observations should weaken conclusions that depend on current positions. |
| K10 | Comparing options | State the objective and assumptions supporting a preference. |
| K11 | Unsupported option | An action outside the model should remain unranked. |
| K12 | Explanation | Show the relevant observation or calculation and its limitation. |
