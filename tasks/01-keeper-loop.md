# Keeper loop: public status

## Goal

Replay three fictional keeper decisions, choose before the outcome, inspect frozen evidence and reveal an authored continuation. Facts are computed in code. Agents explain and review them.

## Implemented

Three synthetic scenarios, immutable observations, route/pressure analysis, five read-only MCP tools, Microsoft Agent Framework analyst/reviewer roles and labelled recorded-agent inspection. Fan view presents plain-language findings; Analyst view exposes timings, assumptions, observation identity and the captured handoff. View changes do not rewrite the choice, snapshot or AI capture.
